# Part 6 - Advanced State Management

In this part, I learned different ways to manage application state outside React components. I worked with Redux, Redux Toolkit, reducers, actions, and the Redux store. I also learned how to communicate with a backend from a Redux application using asynchronous action creators and the Fetch API. Finally, I explored alternative state management solutions such as React Query, `useReducer`, and React Context.

## Topics covered

- Flux architecture
- Redux
- Reducers
- Actions and action creators
- Redux store
- Testing reducers with Vitest
- React Redux
- Redux Toolkit
- Redux DevTools
- Asynchronous action creators
- Redux Thunk
- Fetch API
- React Query
- Server state management
- React Context
