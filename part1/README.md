# Part 1 - Introduction to React

In this part, I started working with React and reviewed the JavaScript concepts needed to use it effectively. I learned how to set up projects with Vite, build reusable components, use JSX, and pass data through props. I also worked with component state using the `useState` hook, handled events, practiced conditional rendering, and learned basic debugging techniques for React applications.

## Topics covered

- React basics
- Vite project setup
- JSX
- Components
- Props
- JavaScript fundamentals for React
- Arrays and objects
- Arrow functions
- Component state with `useState`
- Event handling
- Conditional rendering
- Debugging React apps
- Rules of Hooks
