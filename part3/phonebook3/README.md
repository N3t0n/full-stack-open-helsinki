# Part 3 - Programming a Server with Node.js and Express

- Link to the app:
  https://back-phonebook-fsh.fly.dev/

In this part, I shifted the focus to backend development by learning how to build a server with Node.js and Express. I created RESTful APIs, connected the application to a MongoDB database using Mongoose, and deployed the full stack application to the internet. I also worked with middleware, validation, error handling, and code quality tools such as ESLint.

## Topics covered

- Node.js + Express applications
- RESTful APIs
- HTTP requests and responses
- Middlewares
- CORS
- Environment variables
- Deploying applications to Render / Fly.io
- MongoDB Atlas
- Mongoose
- Schema models
- CRUD operations with databases
- Validation with Mongoose
- Error handling middleware
- Async operations with promises
- ESLint
