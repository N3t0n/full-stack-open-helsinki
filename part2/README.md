# Part 2 - Collections, Forms and Server Communication

In this part, I continued working with React by learning how to render collections of data, organize code into reusable modules, and handle forms with controlled inputs. I also learned how to fetch, create, update, and delete data from a server using `axios` and `useEffect`. Additionally, I worked with external APIs, handled errors and notifications, and applied basic styling to React applications.

## Topics covered

- Rendering collections with `map`
- The `key` prop
- Modules and component organization
- Forms and controlled inputs
- Filtering data
- `axios`
- `useEffect`
- `json-server`
- RESTful APIs
- Creating, updating and deleting data
- Service modules
- Notifications and error handling
- Styling React applications
- External APIs
- Environment variables in Vite
