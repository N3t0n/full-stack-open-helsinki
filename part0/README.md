# Part 0 - Fundamentals of Web Applications

In this part, I reviewed the fundamentals of web development, including HTML, CSS, forms, how the browser works, and communication with the server through HTTP. I also learned the difference between a traditional web application and a SPA. Finally, I completed exercises in which I represented different application flows using sequence diagrams with Mermaid.

## Topics covered

- HTML
- CSS
- Forms
- HTTP
- Browser-server communication
- Traditional web applications vs SPA
- Sequence diagrams with Mermaid
